# Plans

This folder contains active project plans and todo lists.

## Conventions

- One file per feature area or milestone: `feature-name.md`
- Plans are **updated in place** as work progresses — don't delete completed items,
  mark them done. The history of what changed and why is useful.
- A plan file should exist **before** implementation starts for any non-trivial work.

## Status markers

Use these consistently so Claude can parse plan state at a glance:

```
- [ ] Not started
- [~] In progress
- [x] Done
- [-] Deferred / won't do (add a note explaining why)
```

`docs/plans/user-authentication.md`
